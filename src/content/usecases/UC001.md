### Problem
Incoming project enquiries arrive at irregular intervals and require rapid triage without manual mailbox checking.

### Trigger
An incoming HTTP POST request from a web contact form delivering JSON formatted enquiry data.

### Method
1. Receive incoming payload and validate request authentication header.
2. Verify customer email domain and format.
3. Record raw payload into relational database audit log.
4. Dispatch notification to internal ops channel.

### Execution Log

### Failure Modes and Recovery
If the destination database is unreachable, the execution queues the payload to a persistent retry storage node. Alerts trigger after three consecutive retry failures.

This is a reference build and not a client project. You can inspect the structure, review the failure mitigations, and adapt the logic to your operational pipeline.
