### Problem
Broken links and missing canonical tags damage search engine visibility when left unaddressed between major site releases.

### Trigger
A scheduled cron trigger running weekly outside peak business hours.

### Method
1. Read current sitemap XML document and parse listed location URLs.
2. Send HTTP HEAD requests to verify status codes across all endpoints.
3. Flag redirect chains and missing canonical headers.
4. Export clean summary report to internal workspace.

### Execution Log
Sample run recorded in simulation environment:
- Status: 200 OK simulation
- Duration: 4200ms estimate
- Target host: example.com

### Failure Modes and Recovery
When target endpoints return rate limit headers, the worker backs off exponentially. Unresponsive paths are recorded in a separate exception report.

### Inspect and Adapt
This is a reference build and not a client project. The execution steps and alerting thresholds can be adjusted to match your URL count and hosting environment.
